## What Is ExamPulse AI?

ExamPulse AI provides an interactive, AI-supported way for university students to prepare for exams in a web browser. Its study flow focuses on revisiting academic concepts with assistance from the Gemini API.

By combining organized revision with AI features, the tool gives learners a single place to work through concepts before university examinations. It is built for students who want a focused and repeatable approach to exam preparation.

## Gemini API Configuration

Gemini API access is the main external integration used by ExamPulse AI. Set up the API connection using the configuration approach defined by the project files and the environment where the application is deployed.

Store the settings where the application expects them. Never expose API credentials in client-side files or add private keys to version control.

For example:

```env
GEMINI_API_KEY=your_api_key_here
```

Local development and the hosted web build may use different configuration procedures.
